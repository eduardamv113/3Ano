# 2. Inteligência Artificial

## Definições
- **Priberam:** Ramo da ciência da computação que estuda sistemas computacionais com base no conhecimento sobre a inteligência humana.
- **John McCarthy (1956):** *"Making a machine behave in ways that would be called intelligent if a human were so behaving."*
- **Luís Moniz Pereira (2001):** *"A IA pretende construir entidades inteligentes — é uma ciência do artificial, semelhante a uma engenharia."*

## Porquê não basta a programação clássica? — Explosão Combinatória

| Tamanho do Puzzle | Combinações |
|---|---|
| 2×2 | 24 |
| 3×3 | 362.880 |
| 8×8 | ~1,27 × 10⁸⁹ |

> ⚠️ Com 10⁹ combinações/segundo, o puzzle 8×8 demoraria **4 × 10⁶⁹ milénios** por força bruta.  
> → Força bruta é inviável. São necessárias **heurísticas e aprendizagem**.

# 3. Hard Computing vs. Soft Computing

| | Hard Computing (Simbólico) | Soft Computing (Não Simbólico) |
|---|---|---|
| **Base** | Lógica e regras | Dados e aprendizagem |
| **Mecanismo** | Sistemas de inferência | Aprende padrões e generaliza |
| **Características** | Preciso, determinístico, pouco flexível | Tolera incerteza, imprecisão e aproximação |
| **Modelo** | Computação formal | Mente humana |

> 💡 Soft Computing também chamado: **Computational Intelligence** / **Natural Computing**

## Técnicas de Soft Computing
- Fuzzy Logic
- **Redes Neuronais Artificiais**
- Computação Genética e Evolutiva
- Raciocínio Probabilístico
- Particle Swarm Optimization / Ant Colony

## Algoritmos Genéticos (Soft Computing)
Inspirados na **evolução natural de Darwin**. Funcionamento:
1. Criar **população** de soluções candidatas
2. Avaliar cada solução (*fitness*)
3. Gerar nova **geração** com operadores genéticos:
   - Seleção → Cruzamento → Mutação → Purificação
4. Repetir até encontrar boa solução

> 💡 Soluções evoluem ao longo do tempo — as "mais aptas" sobrevivem.

# 4. Big Data & Machine Learning

## Big Data — Os 5 V's

| V | Descrição |
|---|---|
| **Volume** | Quantidade massiva de dados |
| **Velocidade** | Rapidez de geração e processamento |
| **Variedade** | Diferentes tipos e formatos |
| **Variabilidade** | Inconsistência dos dados ao longo do tempo |
| **Valor** | Utilidade dos dados para gerar conhecimento |

> Big Data → base do Machine Learning

## A Mudança de Paradigma

```
Antes (Programação clássica):   INPUT  +  PROGRAMA  →  OUTPUT
Agora (Machine Learning):       INPUT  +  OUTPUT    →  PROGRAMA (aprendido)
```

> Em ML, os dados e os resultados conhecidos são usados para **aprender o modelo automaticamente**.

## Machine Learning — Definição
- **Tom Mitchell (1997):** Construir programas que **automaticamente melhoram com experiência**
- **Característica chave:** Algoritmos são **data-driven** — aprendem a partir de exemplos, sem que a solução seja codificada explicitamente

## 5.1 Aprendizagem com Supervisão *(Supervised Learning)*

**Definição:** Os dados de treino contêm **input (x) e output (y)** conhecidos → algoritmo aprende a função `y = f(x)`

- Chamada "supervisionada" porque existe um **professor/treinador** que supervisiona
- É o paradigma **mais utilizado** em ML

### Subcategorias

| Tipo | Resultados | Exemplos de Aplicação |
|---|---|---|
| **Classificação** | Discretos (categorias) | Deteção de fraude, classificação de imagem, diagnóstico médico, fidelização de clientes |
| **Regressão** | Contínuos (valores numéricos) | Previsão meteorológica, previsão de mercados, crescimento populacional, esperança média de vida |

---

## 5.2 Aprendizagem sem Supervisão *(Unsupervised Learning)*

**Definição:** Existem **apenas inputs (x)**, sem outputs correspondentes → o algoritmo descobre padrões por si próprio

- Objetivo: **modelar a estrutura ou distribuição dos dados**

### Subcategorias

| Tipo | Objetivo | Exemplos de Aplicação |
|---|---|---|
| **Segmentação (Clustering)** | Organizar dados em grupos coerentes | Segmentação de clientes, sistemas de recomendação, marketing |
| **Associação / Redução** | Descobrir regras e reduzir dimensionalidade | Visualização Big Data, descoberta de estruturas, seleção de atributos |

> 🛒 Exemplo de Associação: *"Pessoas que compram bebidas açucaradas não compram bebidas alcoólicas."*

---

## 5.3 Aprendizagem por Reforço *(Reinforcement Learning)*

**Definição:** Sem outputs conhecidos, mas com **feedback de recompensa/penalização** sobre os resultados produzidos

- ❌ Não é Supervisionada — não há professor/treinador
- ❌ Não é Não Supervisionada — existe alguma informação sobre os resultados (boa/má)
- ✅ A aprendizagem dá-se pela **capacidade de crítica sobre os próprios resultados**

### Algoritmos
| Algoritmo | Descrição |
|---|---|
| **Q-Learning** | Assume política ótima e usa-a para atualizar os valores das ações |
| **SARSA** | Considera a política atual em execução para atualizar os valores das ações |

### Aplicações
- Decisões em tempo real
- Navegação de robôs
- Aquisição de aptidões
- **Jogos com IA** (AlphaGo, Deep Blue vs. Kasparov)

---

## 5.4 Comparação Rápida dos 3 Paradigmas

| | Supervisionada | Não Supervisionada | Por Reforço |
|---|---|---|---|
| **Dados rotulados?** | ✅ Todos | ❌ Nenhum | ⚠️ Parcialmente |
| **Professor?** | ✅ Sim | ❌ Não | ❌ Não |
| **Tipo de feedback** | Comparação com labels | Funcionamento interno | Recompensa / Penalização |
| **Subcategorias** | Classificação, Regressão | Clustering, Associação | Q-Learning, SARSA |
| **Exemplos** | Diagnóstico, Previsão | Segmentação clientes | Jogos, Robótica |

# 6. Aprendizagem Semi-Supervisionada

**Definição:** Combina **poucos dados rotulados** com **muitos dados não rotulados**, para melhorar a qualidade dos modelos minimizando o esforço de etiquetagem.

## Métodos

### Wrapper Methods
| Método | Como funciona |
|---|---|
| **Self-training** | 1. Treina com dados rotulados → 2. Prevê novos → 3. Adiciona previsões confiáveis ao treino → 4. Itera |
| **Co-training** | Dois modelos treinam com perspetivas "alternativas" e partilham previsões mutuamente |

### Outros Métodos
- **Graph Methods** — representam dados como grafos; calculam similaridade entre nodos
- **GANs (Generative Adversarial Networks)** — arquitetura Gerador vs. Discriminador

## Desafios
- Qualidade dos dados sem output
- Sensibilidade à distribuição dos dados
- Complexidade dos modelos
- Aplicabilidade limitada

## Exemplos de Aplicação
- Áudio / Vídeo
- Classificação de texto (análise de sentimentos)
- Deteção de fraude
- Conteúdos web

# 9. 🎯 Pontos-Chave para o Exame

| Tema | O que saber |
|---|---|
| **ML é data-driven** | Aprende a partir de exemplos, sem codificação explícita da solução |
| **Supervisionada** | Dados com labels → `y = f(x)` → Classificação (discreta) ou Regressão (contínua) |
| **Não Supervisionada** | Sem labels → Clustering (agrupamento) ou Associação/Redução |
| **Reforço** | Sem labels mas com recompensa/penalização → aprende por tentativa e erro |
| **Semi-supervisionada** | Mistura dados rotulados e não rotulados; métodos: Self-training, Co-training, GANs |
| **Soft Computing** | Tolera imprecisão; modelo = mente humana; ≠ Hard Computing (lógica rígida) |
| **Big Data** | 5 V's: Volume, Velocidade, Variedade, Variabilidade, Valor |
| **Paradigma atual** | Antes: INPUT+PROGRAMA=OUTPUT → Agora: INPUT+OUTPUT=PROGRAMA |
| **Algoritmos Genéticos** | Evolução natural; operadores: seleção, cruzamento, mutação |
| **Redes Neuronais** | Evolução desde 1943; AI Winter após XOR problem; ressurgimento com Deep Learning |
